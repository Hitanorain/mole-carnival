# 地鼠嘉年华 · Mole Carnival

单文件网页打地鼠游戏，手机、平板、电脑都能玩：用手指或鼠标挥动玩具锤，敲冒出来的地鼠。

不只是打地鼠：

- **11 种角色**：小地鼠、一闪就跑的金地鼠、要敲两下的头盔地鼠、打一下就换洞逃跑的小偷地鼠、冻住全场的冰冰地鼠、一口气劈晕全场的闪电地鼠、加时间的闹钟地鼠……还有**别打**的小兔子和炸弹
- **连击和超级锤子**：连击满 10 下，锤子变金色、分数翻倍，按住划过去就能连着打
- **神速奖励**：地鼠刚冒头就打中有额外加分；让地鼠溜走会断连击
- **地鼠大王**：每个世界第 10 关，打 3 下就钻走换洞，还会扔泥巴糊住屏幕（点泥巴能擦掉）
- **闯关模式**：🌼 春日花园、🍉 夏日沙滩、⛄ 冬日雪原三个世界共 30 关，洞越来越多、地鼠越来越快；第一个世界每关介绍一位新角色
- **60 秒挑战**：越打越快，记录最高分
- **双人对战**：平板平放在桌上，两人面对面各守一半。打中礼物地鼠给对手送去一波炸弹和小兔子，进入超级锤子时对手屏幕会被糊上泥巴

画面全部用 canvas 画，音乐和音效用 Web Audio 合成。直接用浏览器打开 `index.html` 就能玩；进度保存在浏览器本地。
